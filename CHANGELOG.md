# Histórico de versões

O arquivo para download de cada versão está em [Releases](https://github.com/glpisalvador/monitorfilas/releases).

## 1.0.1 — 2026-09-30

Primeira versão publicada. Sucessor do antigo plugin "monitoramentodegrupos".

- Painel em tempo real das filas dos grupos com status reais do GLPI, técnicos, faixas de SLA, itens parados e rankings.
- Números clicáveis que abrem a busca nativa já filtrada.
- 1.0.1: os grupos podem entrar nas filas como **atribuído, observador ou ambos** (padrão: ambos).
